# Saját fotók — hiánylista

A brief fotóigénye: hero 21:9, mobilon 4:5; Tai Chi 4:5; Fák Bölcsessége 3:2; portré 4:5; megosztási kép 1200×630. Termékborító csak tényleges termék esetén szükséges.
