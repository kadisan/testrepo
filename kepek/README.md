# Képek

Ide kerülnek a weboldalhoz használt eredeti fotók.

Feltöltés: **Add file → Upload files**, majd **Commit changes**.

A képeket közvetlenül feltöltheted JPG-, PNG- vagy WebP-formátumban; ZIP nem szükséges. Az eredeti fájlneveket megtarthatod.

Az eredeti fotók megmaradnak; a portrékivágások és a webes változatok külön készülnek.
